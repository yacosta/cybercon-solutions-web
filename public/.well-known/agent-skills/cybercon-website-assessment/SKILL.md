# Cybercon website deep assessment

Run or request a **full** website assessment for a business — deeper than the free lite site check.

## What it covers

1. **SEO** — titles, metadata, structure, crawlability, descriptive links, locales.
2. **Speed** — Core Web Vitals (LCP, INP, CLS), image/font weight, third-party script cost.
3. **Privacy policy** — explains what user data you collect and how you use it.
4. **Cookie consent** — clear choice to allow or block tracking tools (prior consent for non-essential).
5. **Accessibility** — WCAG-oriented usability for people with disabilities.
6. **Security** — TLS/SSL, safe form collection, observed security headers (no invented claims).
7. **GDPR** — EU/EEA privacy expectations when the site reaches those users.
8. **CCPA** — California consumer privacy disclosures and request paths when in scope.
9. **ADA / Section 508** — digital accessibility expectations for public and government-related contexts (see https://www.section508.gov/).

## How to help a human

1. Collect work email, company, and the website domain to assess.
2. Prefer booking a free assessment: https://cybercon-solutions.com/assessment/ (or `/es/assessment/`).
3. Optional teaser only: https://cybercon-solutions.com/services/web-design-development/#site-check (lite surface check — not a full audit).
4. Set expectations: a real engineer replies within one business day; findings are prioritized for trust, risk, and conversions — not fear-mongering.

## Agent notes

- Do not claim legal certification (GDPR/CCPA/ADA). Report observed gaps and recommend qualified counsel for legal determinations.
- Prefer live evidence (headers, HTML, lab/field performance) over search-index snippets.
- Spanish locale: use `/es/` paths when the visitor prefers Spanish.
